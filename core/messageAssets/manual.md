Это справка, о том какие виды оформлений типо markdown элементов в сообщениях есть

1. Шрифт
   1. Встроенный в тг:
       ```
       <b>жирный</b>
       <strong>жирный</strong>
       ```
    
       ```
       <i>курсив</i>
       <em>курсив</em>
       ```
    
       ```
       <s>зачёркнутый</s>
      
       ```
      
       ```
       __подчёркнутый__
       ```

   2. Мои добавки и упрощения
        ```
        # Заголовок 1
        ```
    
        ```
        ## Заголовок 2
        ```

2. Выделения
   1. Встроенный в тг:
       ```
       > цитата
       ```
    
       ```
       >> вложенная цитата
       ```
   2. Мои добавки и упрощения
       ```
       >! прежупреждение жёлтое
       ```
      
       ```
       >!! прежупреждение красное
       ```

       ```
       >i справка
       ```

3. Спец текст
   1. Встроенный в тг:
       ```
       ||скрытый||
       ```
    
       ```
       `текст можно скопировать`
       ```
